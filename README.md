# clickpoint.

Upload notes. Get a Duolingo-style pathway. Learn the card. Survive the checkpoint.

## Setup

1. Copy `.env.example` to `.env.local`
2. Put your Hack Club AI key in `LOGFARE_API_KEY` (https://ai.hackclub.com)
3. `npm install`
4. `npm run dev`

Open [http://localhost:3000](http://localhost:3000)

## Flow

1. Landing page: paste notes or upload PDF / PPTX / TXT
2. Wait for syllabus + banner + card 1
3. Walk the pathway. Later cards generate in the background
4. Finish lesson → 8-question checkpoint → 75% unlocks the next card
